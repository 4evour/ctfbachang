# DedeCMS 代码执行（CNVD-2018-01221）

> **一句话打法：**用管理员后台会话调用 `tpl.php?action=savetagfile`，将 PHP 内容写入 `include/taglib/*.lib.php`，再访问该文件确认 PHP 执行。[S1][S2][S3]

题库镜像：`vulfocus/dedecms-cnvd_2018_01221:latest`；容器端口：`80,3306`。公开分析对应 DedeCMS v5.7 SP2 后台 `dede/tpl.php` 标签文件写入点；请求前需通过 `CheckPurview('plus_文件管理器')` 权限检查。[S1][S2][S3]

## 操作步骤

1. 登录题目后台并保持当前会话。默认后台路径为 `/dede/`，如被改名则替换为实际路径。该题 Vulfocus 专题复现使用管理员后台会话。[S1]

2. 在同一会话中请求 `savetagfile`，文件名使用符合过滤规则的 `probe_018.lib.php`，内容使用 URL 编码后的 `<?php phpinfo();?>`。Vulfocus 对应镜像的公开复现请求使用空 token；文件写入 `include/taglib/` 目录。[S1][S2]

```text
http://<靶场IP>:<映射端口>/<后台路径>/tpl.php?action=savetagfile&token=&filename=probe_018.lib.php&content=%3C%3Fphp%20phpinfo()%3B%3F%3E
```

3. 访问 `/<站点路径>/include/taglib/probe_018.lib.php`；出现 PHPInfo 页面即表明文件已写入并由 PHP 执行。[S1][S2][S3]

## 本题特有排坑

- 账号需通过 `plus_文件管理器` 权限检查；仅有普通后台登录态不够。公开 Vulfocus 镜像复现的请求使用空 `token=`，但代码审计与安全公告所示的 v5.7 SP2 代码会执行 `csrf_check()`。若空 token 被拒绝，访问 `/<后台路径>/tpl.php?action=upload` 从页面源码取 token，再沿用同一会话重放写入请求。[S1][S2][S3]
- 文件名必须匹配 `^[a-z0-9_-]{1,}\.lib\.php$`，如 `probe_018.lib.php`；生成文件位于 `include/taglib/`，不是后台目录。[S1][S2]
- 默认后台路径为 `/dede/`，被改名时要同步替换；Vulfocus 专题文章给出的镜像映射为 HTTP 80、MySQL 3306，实际访问使用靶场实例映射端口。[S1]
